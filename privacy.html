Privacy Policy

AI Driving Uploader, the private upload tool for the developer's own YouTube channels, such as Last Lap Daily (@lastlapdaily)

Effective date: October 30, 2026

1. What this app is

AI Driving Uploader is a private desktop tool. Its only user is the developer, on YouTube channels the developer owns and operates (currently Last Lap Daily). It uploads those channels' own gameplay videos, sets their titles, descriptions, thumbnails and playlists, and reads their own statistics. It is not offered to the public, has no user accounts and does not serve ads.

2. Use of YouTube API Services

This app uses YouTube API Services (the YouTube Data API v3 and the YouTube Analytics API).

  • By using this app you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms).
  • Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

3. Information the app accesses

With the developer's permission, given through Google sign-in (OAuth) for each channel, the app accesses only the developer's own channels:

  • Upload and manage videos (youtube.upload, youtube.force-ssl): upload videos, set titles, descriptions, tags, thumbnails, visibility and playlists.
  • Read the channel (youtube.readonly): channel name, the channel's own videos and their view counts.
  • Read channel analytics (yt-analytics.readonly): views, watch time and similar totals for the channel's own videos.

For keyword research the app may also read public information about public videos (titles, tags, length, view counts) through the YouTube Data API. It never accesses private information of other users or viewers, and it does not collect names, email addresses, comments or any other personal data of viewers.

4. How the information is used

  • To upload and schedule the channels' own videos and keep their titles, descriptions and playlists up to date.
  • To show the developer how the videos perform, so better videos can be made.

The information is not used for advertising, profiling, or any other purpose.

5. Storage

  • The Google sign-in token is stored only on the developer's own computer, in a private folder that is never uploaded or shared.
  • Statistics read from the API are kept as files on the same computer. The app has no server and no cloud database.

6. Sharing

No information obtained through YouTube API Services is sold, shared with, or disclosed to any third party.

7. Cookies

The app is a desktop tool and does not place cookies or similar technologies on any device. This page does not use cookies.

8. Data retention and deletion

  • Information obtained from YouTube API Services is kept no longer than 30 days unless it is refreshed from the API, and is deleted when it is no longer needed.
  • The sign-in token is deleted as soon as access is revoked or on request.
  • To ask for deletion of any stored data, write to the contact address below; it is deleted within 7 days.

9. Revoking access

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the app can no longer read or change anything on that channel.
