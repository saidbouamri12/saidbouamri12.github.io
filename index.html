AI Driving Uploader

The private upload tool for the developer's own YouTube channels, such as Last Lap Daily: mobile racing game Shorts, every day.

Watch Last Lap Daily on YouTube

What it does

  • Uploads each channel's own gameplay Shorts to YouTube on a daily schedule.
  • Sets each video's title, description, tags, thumbnail and playlist.
  • Reads each channel's own view counts and analytics to see which videos work best.

Who can use it

Only the developer, on YouTube channels the developer owns and operates. The tool runs on the developer's own computer, signs in with Google (OAuth) for each channel and touches nothing else. It is not offered to the public and has no other users.

YouTube API Services

This tool uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). Its use is subject to the YouTube Terms of Service and the Google Privacy Policy.
